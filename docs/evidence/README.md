# Evidence

PRD 수용기준과 실제 구현·테스트·런타임 결과를 연결한다.

## 현재 증거

- [업무 연속성 수용 증거](../work-continuity-acceptance-evidence.md)
- [Evidence template](../templates/evidence-template.md)

## 원칙

- 실행한 명령과 결과만 기록한다.
- 자동 테스트, 코드 연결, 수동 검증과 외부 gap을 구분한다.
- 날짜, 대상 commit과 환경을 적는다.
- 이후 코드가 바뀌면 기존 결과가 여전히 유효하다고 가정하지 않는다.
