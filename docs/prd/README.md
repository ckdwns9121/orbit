# Product Requirements and Specs

## 현재 기준

- [Orbit 개인 업무 연속성 PRD](prd-orbit-work-continuity.md)
- [Orbit 개인 업무 연속성 Spec](spec-orbit-work-continuity.md)

## 역할 구분

- PRD: 사용자 문제, 목표·비목표, 범위, 성공 지표와 수용기준을 소유한다.
- Spec: 사용자 흐름, 상태, 데이터/API 계약과 테스트 시나리오를 소유한다.
- Technical Design: 구현 세부, migration, rollout과 observability를 소유한다.

새 기능은 [PRD template](../templates/prd-template.md)과 [Spec template](../templates/spec-template.md)에서 시작한다.
