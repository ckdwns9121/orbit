## Background

AI를 사용하면 여러 작업을 동시에 실행할 수 있지만 사람의 현재 주의력은 하나의 업무에만 집중할 수 있다. 단순한 `진행 중` 상태만으로는 지금 무엇을 해야 하는지 명확하지 않고, 복수 focus를 허용하면 컨텍스트 스위칭 문제를 다시 만든다. 앱과 메뉴바가 같은 집중 상태를 보려면 UI 메모리가 아닌 영속적 단일 계약이 필요하다.

## Decision

진행 중 Task와 별도로 최대 하나의 Task만 차지할 수 있는 영속 focus slot을 둔다. 획득·교체·해제는 revision 검증과 체크포인트를 포함한 중앙 전이 명령으로 처리한다.

## Options

| Option | Pros | Cons |
| --- | --- | --- |
| DB 단일 focus slot | 앱·메뉴바·재기동 간 일관성과 원자적 교체 보장 | 전이 계약이 복잡해짐 |
| Task별 focus boolean | 모델이 단순해 보임 | 복수 true 방지와 교체 원자성이 어려움 |
| UI 선택 상태만 사용 | 구현 비용이 낮음 | 재기동 복구와 여러 window 일관성이 없음 |

**최종 결정:** SQLite singleton slot과 CAS revision을 사용해 단일 집중을 보장한다.
