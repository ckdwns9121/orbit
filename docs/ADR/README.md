# Architecture Decision Records

확정된 기술·제품 결정을 시간순으로 보존한다. 기존 결론을 뒤집을 때는 원문을 수정하지 않고 새 ADR로 대체한다.

## 상태

- Draft: 아직 결정되지 않음
- Accepted: 현재 적용되는 결정
- Superseded: 새 ADR로 대체됨
- Deprecated: 더 이상 적용하지 않음

## 작성 방법

1. 다음 사용 가능한 번호를 선택한다.
2. [ADR template](../templates/adr-template.md)을 복사한다.
3. context, decision, options, consequences와 검증 방법을 작성한다.
4. 관련 Architecture·Policy·Technical Design을 연결한다.
